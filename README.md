Минималистичный Android-лаунчер в вайб-стиле.

**Тёмный неоновый дизайн • Большие часы • Свайп вверх → App Drawer • Поиск**

---

## Как собрать APK с телефона (через GitHub)

### 1. Создай новый репозиторий на GitHub
- Зайди на [github.com/new](https://github.com/new)
- Название: `VibeLauncher` (или любое)
- **Public**
- **Не** ставь галочки на README / .gitignore

### 2. Залей проект

**Самый простой способ с телефона:**

1. Скачай этот архив `VibeLauncher.zip`
2. Распакуй его
3. Зайди в созданный репозиторий на GitHub
4. Нажми **Add file → Upload files**
5. Загрузи **все** файлы и папки из архива
6. Нажми **Commit changes**

### 3. Собери APK

1. Перейди во вкладку **Actions**
2. Выбери workflow **Build APK**
3. Нажми **Run workflow** → **Run workflow**
4. Подожди 2–4 минуты
5. Когда сборка станет зелёной — нажми на неё
6. Внизу в разделе **Artifacts** скачай `VibeLauncher-debug`
7. Распакуй zip → внутри будет `.apk`
8. Установи APK на телефон
